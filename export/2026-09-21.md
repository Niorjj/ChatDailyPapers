### 1. ZYT-World: A Real-Time Controllable World Model for Closed-Loop Autonomous-Driving Simulation

- **方向/评分**：交叉方向 · 92/100
- **作者**：Boni Hu, Xiong Wei, Haoming Huang, Yong Huang, Chenbo Wang, Yi Yang, Jiancheng Wang, Ruicheng Zhu 等
- **链接**：[arXiv](http://arxiv.org/abs/2609.21712v1) · [PDF](https://arxiv.org/pdf/2609.21712v1)
- **推荐理由**：同时涉及多模态生成（世界模型）和模型加速（量化、蒸馏、推理优化），是交叉方向的典型代表，与目标研究方向高度契合。
- **研究问题**：自动驾驶世界模型的生产部署面临三大挑战：(1) 以原生分辨率忠实复现混合鱼眼-针孔相机阵列；(2) 在因果逐帧交互与长程稳定性和低延迟之间取得平衡；(3) 场景重访时保持场景一致性。
- **核心方法**：提出 ZYT-World 单一架构：(1) 原生生成4个鱼眼视图（FOV>180°）和3个针孔视图，使用投影特定的Plucker适配器编码相机几何；(2) 自车运动自适应层归一化提供全局运动控制；(3) 轻量级像素对齐布局通过实例级框、朝向和颜色条件化交通参与者和信号灯；(4) 异构训练结合全阵列几何覆盖与高分辨率细节；(5) 通过教师强制、因果一致性蒸馏、自展开分布匹配蒸馏和RigCritic将40步双向教师模型转化为单步逐latent流式生成器；(6) 19M参数TinyVAE解码器、W8A8量化和推理引擎分别降低解码、骨干网络和增量执行成本；(7) 跨轨迹对训练即插即用隐式记忆模块保持地点特定证据。
- **主要结果**：一步模型保留教师模型90%以上的PSNR和SSIM，FID、FVD和LPIPS在教师模型的11%以内；生成器仅计时下比40步双向教师快107.7倍；TinyVAE解码比Wan快59.8倍；30秒展开和跨轨迹重访展示预期的长程和记忆行为。
- **创新点**：
  - 原生混合鱼眼-针孔多视图世界模型
  - 多阶段蒸馏将40步双向模型压缩为单步流式生成
  - TinyVAE+W8A8量化+推理引擎的三层加速策略
  - 跨轨迹隐式记忆模块实现场景重访一致性
- **局限性**：摘要未说明
- **研究启发**：多模态世界模型的部署需要系统性融合量化、蒸馏和推理优化；异构训练和投影特定适配器是多视角生成的重要设计选择。
- **关键词**：世界模型、多模态生成、W8A8量化、蒸馏、推理优化、TinyVAE、自动驾驶

### 2. LiteMedCoT-VL: Parameter-Efficient Adaptation for Medical Visual Question Answering

- **方向/评分**：交叉方向 · 85/100
- **作者**：Runze Ma, Shunbo Jia, Haonan Lyu, Guo Liu, Caizhi Liao
- **链接**：[arXiv](http://arxiv.org/abs/2605.09384v2) · [PDF](https://arxiv.org/pdf/2605.09384v2)
- **推荐理由**：将知识蒸馏(235B→2B)与 LoRA 参数高效微调结合应用于医疗视觉问答，横跨多模态理解与模型优化两大方向，对边缘部署小模型有直接参考价值。
- **研究问题**：大型 VLM 与紧凑型 VLM(2-4B)之间存在推理能力差距，限制了医疗 AI 在便携式设备上的部署；现有知识蒸馏方法仅迁移答案而未迁移推理过程。
- **核心方法**：通过 LoRA 微调将 235B 教师模型的思维链推理迁移到 2B 学生模型，使用解释增强的训练数据；推理默认不使用图像描述，模拟医生直接解读医学影像的场景。
- **主要结果**：在 PMC-VQA 基准上达到 64.9% 准确率，超过 Qwen3-VL-4B 零样本基线(53.9%)11.0 个百分点，超过所有已发表基线；视觉接地分析表明模型依赖图像内容而非文本先验。
- **创新点**：
  - 将思维链推理蒸馏从 235B 教师迁移至 2B 学生模型
  - LoRA 参数高效微调结合解释增强数据
  - 无图像描述推理模拟真实临床场景
- **局限性**：摘要未说明蒸馏过程的训练成本、LoRA 秩的选择敏感性、以及在不同医学影像模态上的泛化效果。
- **研究启发**：可将此蒸馏范式推广至其他多模态边缘部署场景，例如将大型多模态模型的推理能力蒸馏到轻量模型中用于实时视频理解或移动端多模态交互。
- **关键词**：知识蒸馏、思维链、参数高效微调、LoRA、医疗视觉问答、边缘部署

- **主要结果**：Samsone-134M在同尺寸级别多个基准上建立新SOTA。尽管参数紧凑，Samsone系列性能与参数量大数个量级的模型具有竞争力。提供实时端侧推理的Android应用演示。摘要未提供具体数值指标。
- **创新点**：

- **局限性**：摘要未说明。模型规模仍远小于大型音频语言模型，性能上限受限；限于音频语言任务，未涉及多模态融合（如视觉）。
- **研究启发**：小型模型通过精心设计和扩展定律探索达到与大型模型竞争力的思路，可推广至其他多模态任务的边缘部署，如小型视觉语言模型或小型视频理解模型。移动优化检查点的实践对端侧推理部署具有直接参考价值。

## 多模态

### 4. DRT: Dense Reasoning Trace for Efficient and Grounded Multimodal Reasoning

- **方向/评分**：多模态 · 85/100
- **作者**：Wan Xu, Yuanfan Guo, Kevin Han, LaLa Chen, Wangmeng Zuo
- **链接**：[arXiv](http://arxiv.org/abs/2609.21675v1) · [PDF](https://arxiv.org/pdf/2609.21675v1)
- **推荐理由**：直接针对多模态大语言模型的推理效率问题，提出结构化推理轨迹替代自然语言CoT，与多模态理解及推理优化方向高度契合。
- **研究问题**：现有多模态大模型依赖自然语言链式思维（CoT），存在语言冗余、信息稀释和视觉 grounding 薄弱的问题，导致推理效率低。
- **核心方法**：提出 Dense Reasoning Trace (DRT) 范式，以紧凑的结构化轨迹（含符号连接器和视觉观察与逻辑推演的分离）替代自然语言CoT；通过 Dense Trace Initialization 将DRT推理模式内化到模型中；提出 Trace-Grounded Reinforcement Learning 框架，利用三视角验证管线构建参考轨迹，并采用 Trace-Grounded GRPO 配合结构化奖励。
- **主要结果**：在多个推理基准上实现 5.5× 的 token 效率提升，同时比 Qwen3-VL 基线提升 1.3 个准确率点。
- **创新点**：
  - 用结构化紧凑轨迹替代自然语言CoT，显著降低 token 开销
  - Dense Trace Initialization 将推理模式内化到模型中
  - Trace-Grounded RL 结合结构化奖励抑制幻觉并增强逻辑 grounding
- **局限性**：摘要未说明
- **研究启发**：多模态推理不一定需要冗长的自然语言轨迹，结构化表示可能是下一代MLLM更高效的路径。
- **关键词**：多模态推理、token效率、结构化推理轨迹、强化学习、视觉grounding

### 5. Touvigation: Embodied Adaptive Object Acquisition for Blind and Low-Vision Users in Unfamiliar Indoor Environments

- **方向/评分**：多模态 · 72/100
- **作者**：George Xi Wang, Xiangyu Li, Shaoyue Wen, Jiaqian Hu, Junan Xie, Yupeng Wang, Ziyue Shi, Qijun Chen 等
- **链接**：[arXiv](http://arxiv.org/abs/2609.21828v1) · [PDF](https://arxiv.org/pdf/2609.21828v1)
- **推荐理由**：属于具身多模态方向，结合视觉语言理解与空间建模，针对视障用户的物体获取任务，与具身多模态应用高度相关。
- **研究问题**：视障用户在陌生室内环境中定位和获取物体困难；现有视觉语言模型助手存在延迟、幻觉和与具身动作不对齐的问题。
- **核心方法**：提出 Touvigation 免提物体获取系统，结合视觉语言理解与持久本地空间建模；基于8名参与者访谈设计多阶段引导框架，随用户从定向、行走、到达和触觉验证的阶段过渡而自适应调整空间参考。
- **主要结果**：12名视障参与者评估中，Touvigation 任务成功率100%，多模态助手为58%，无辅助搜索为85%；同时降低了完成时间和认知负荷。
- **创新点**：
  - 持久空间建模与视觉语言理解的融合
  - 多阶段自适应具身引导框架
  - 身体相对的低延迟空间引导
- **局限性**：摘要未说明
- **研究启发**：持久空间 grounding 和自适应具身引导可显著提升视障用户的物体获取能力，具身多模态系统需关注空间连续性与动作对齐。
- **关键词**：具身多模态、视觉语言模型、空间建模、视障辅助、自适应引导


## 模型加速与优化

### 6. SpecQuant: Speculative Decoding with Multi-Parent Quantization for Adaptive LLM Inference

- **方向/评分**：模型加速与优化 · 90/100
- **作者**：Harish KB, Jagadeeswaran M, Pradheep P, Yuvanesh S, Sivakumar T
- **链接**：[arXiv](http://arxiv.org/abs/2609.21704v1) · [PDF](https://arxiv.org/pdf/2609.21704v1)
- **推荐理由**：SpecQuant 将多父量化与投机解码结合，实现免训练的自适应 LLM 推理加速，直接涉及量化(INT4/FP8/FP16)、投机解码和推理服务优化，与高效 AI 系统方向高度契合。
- **研究问题**：LLM 本地部署受限于消费级硬件的计算和内存；量化、投机解码和自适应推理各自需重训练、架构调优或草稿模型，难以灵活组合。
- **核心方法**：从共享基座模型派生多个量化变体(INT4/FP8/FP16)，基于预测的查询复杂度动态路由：简单任务用轻量变体，复杂推理或长上下文用全精度模型；共享权重设计保证投机解码的 token 接受率无需额外草稿父模型。
- **主要结果**：在 Qwen2.5 系列模型上，MMLU、AlpacaEval、GSM8K 基准上实现 35-43% 加速，精度下降不超过 2%。
- **创新点**：
  - 多父量化变体共享基座模型，避免独立草稿模型的兼容性问题
  - 基于查询复杂度的动态路由实现自适应推理
  - 免训练框架，无需重训练或架构调优
- **局限性**：摘要未说明对 KV cache 的影响、不同硬件平台的实测延迟差异，以及动态路由预测模块本身的开销。
- **研究启发**：可借鉴其共享权重多量化变体思路，探索在多模态模型中根据输入模态复杂度动态选择精度路径，结合 KV cache 压缩进一步降低边缘部署成本。
- **关键词**：量化、投机解码、自适应推理、免训练加速、边缘部署

### 7. RheoSampling: Resolving the One-Hot Dilemma in Stochastic Dynamic-Tree Speculative Decoding

- **方向/评分**：模型加速与优化 · 90/100
- **作者**：Qiao Hu, Yepeng Weng, Bo Zhang, Takehisa Yairi
- **链接**：[arXiv](http://arxiv.org/abs/2609.21827v1) · [PDF](https://arxiv.org/pdf/2609.21827v1)
- **推荐理由**：解决动态树投机解码在随机解码下的 one-hot 困境，直接涉及解码优化和投机采样效率，是 LLM 推理加速的核心问题。
- **研究问题**：动态树投机解码方法(如 EAGLE-3)在贪心解码下表现良好，但在随机解码(T>0)下将草稿分布坍缩为 one-hot 概率，导致接受率严重下降；动态树方法牺牲随机采样，静态树方法牺牲上下文感知拓扑。
- **核心方法**：将树构建与 token 验证的概率角色解耦：为采样 token 分配代理概率用于树扩展和剪枝，同时保留真实采样概率用于验证；通过等价类分析建立无损保证，结合 OT 验证策略和稀疏草稿机制。
- **主要结果**：跨多个 LLM 和基准实验表明，相比 SOTA 动态树方法在接受率和加速比上均有提升。
- **创新点**：
  - 解耦树构建与验证的概率角色，解决 one-hot 困境
  - 首个同时支持上下文感知 top-K 构建和随机采样的动态树方法
  - 等价类分析建立无损保证的理论框架
  - OT 验证策略与稀疏草稿机制
- **局限性**：摘要未说明具体加速比数字、不同温度参数下的表现差异、以及与 KV cache 优化的兼容性。
- **研究启发**：解耦设计思想可启发其他推理加速场景中的概率分配问题；稀疏草稿机制可结合量化或稀疏化技术进一步优化草稿阶段开销。
- **关键词**：投机解码、动态树、随机采样、解码优化、无损保证

### 8. Draft-OPD: On-Policy Distillation for Speculative Draft Models

- **方向/评分**：模型加速与优化 · 88/100
- **作者**：Haodi Lei, Yafu Li, Haoran Zhang, Shunkai Zhang, Qianjia Cheng, Xiaoye Qu, Ganqu Cui, Bowen Zhou 等
- **链接**：[arXiv](http://arxiv.org/abs/2605.29343v3) · [PDF](https://arxiv.org/pdf/2605.29343v3)
- **推荐理由**：直接针对推测解码中的草稿模型训练问题，提出在策略蒸馏方法，与解码加速和蒸馏方向高度相关。
- **研究问题**：推测解码中草稿模型通常通过SFT在目标模型生成的轨迹上训练，但SFT很快达到瓶颈——接受长度停止提升。原因是离线-推理不匹配：SFT学习固定轨迹，而推测解码在草稿模型自身策略下评估。
- **核心方法**：提出 Draft-OPD：利用目标辅助展开获得稳定续写，并从验证暴露的错误位置重放草稿生成；使草稿模型能从目标反馈中学习已接受和已拒绝的提案，聚焦于限制推测接受率的草稿诱导错误。
- **主要结果**：在多种任务的思考模型上实现超过5×的无损加速，比EAGLE-3提升23%，比DFlash提升13%。
- **创新点**：
  - 识别SFT在草稿模型训练中的离线-推理不匹配问题
  - 在策略蒸馏结合目标辅助展开与错误位置重放
  - 从已接受和已拒绝提案中联合学习
- **局限性**：摘要未说明
- **研究启发**：推测解码草稿模型的训练需要关注策略一致性，在策略蒸馏是提升接受率的关键方向。
- **关键词**：推测解码、在策略蒸馏、草稿模型、推理加速、SFT瓶颈
